# Hostel Help Desk

A web-based hostel management application designed to simplify complaint reporting, maintenance requests, and communication between students and hostel authorities.

## Overview

Hostel Help Desk helps students raise hostel-related issues in a structured way and allows admins to manage and resolve them efficiently.  
It is built to make hostel issue tracking faster, easier, and more organized.

## Features

- Student complaint submission
- Maintenance request management
- Complaint status tracking
- Admin dashboard
- Notice and updates section
- Easy and organized communication

## Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## Installation

### Prerequisites
Make sure you have the following installed:
- Python 3.x
- pip
- Git

### Steps

```bash
git clone https://github.com/your-username/hostel-help-desk.git
cd hostel-help-desk
```

```bash
pip install -r requirements.txt
```

```bash
python app.py
```

## Usage

1. Open the application in your browser.
2. Register or log in as a student/admin.
3. Submit or manage hostel complaints.
4. Track the status of each request.
